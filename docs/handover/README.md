# Affsiwen — полная передача проекта

Дата передачи: **8 октября 2026**, Europe/Madrid. Этот документ и соседние файлы — точка входа для следующего разработчика/оператора. Более ранние записи сохраняются как история, но не заменяют этот checkpoint.

## Что за продукт

Affsiwen продаёт результат исследования публичных данных в собственном интерфейсе. Клиент выбирает знакомую площадку, описывает задачу в чате, получает уточнения и согласованный состав выгрузки. Сервер выбирает допустимую операцию поставщика. План коммерческого пути: цена → оплата Affsiwen → управляемый сбор → таблица/CSV → поддержка. Сейчас цена, оплата и платное исполнение ещё не прошли коммерческую приёмку.

Продукты объединяют операции одной площадки. Покупатель видит Amazon, Zillow и другие источники данных; инфраструктурный поставщик не рекламируется в покупательском интерфейсе. «Agent» — название продукта Affsiwen, а не обещание автономной закупки инструментов. Рейтинг и Hot — редакционный выбор, не статистика продаж Affsiwen.

## Два варианта кода — не перепутать

**Текущая публикация:** `api/index.mjs` → `cloud/backend.mjs` → Supabase; статический интерфейс собирается из `dist/` в `public/`. Vercel использует `vercel.json`. Cloud-release — выбранный для публикации набор файлов, с cloud README/package и сокращённым `server/catalog.mjs`.

**Исторический локальный прототип:** `server/http.mjs`, SQLite, Apify-адаптер, Docker/Render и исходный корневой `package.json` с `npm start`. Они включены в снимок, потому что это часть сделанной работы; `npm start` из workspace-source НЕ запускает текущий облачный backend. Не выкладывать весь workspace поверх production. Для продолжения Vercel начать с `cloud-release/` или канонического GitHub.

Local Git remote у рабочего checkout указывает на старый `euroaffcloud-Roman/affsiwen-platform`; он не является каноническим целевым репозиторием. Локальный Git HEAD не отражает браузерные коммиты в `affsiw7/Affsiwen-platform`. Не делать слепой push/reset/force-push.

## Границы передачи

Исходники, все тесты, SQL, брендовые assets, исследования, планы и исторические документы сохранены. В публичном снимке внутренние PLAN/PROJECT_LOG заменены уже подготовленными публичными версиями; личные контакты/внутренние бюджеты скрыты. ZIP в рабочей папке дополнительно содержит папку `local-only-records` с исходными внутренними текстовыми исследованиями/журналами: это архив для владельца, **не файл для загрузки в публичный GitHub**.

Ключи, cookies, локальные базы, клиентские данные, `.git`, `.openai`, аккаунтные экспорты, зависимости и производный `public/` исключены. ZIP — передача разработки, не резервная копия живой Supabase/поставщиков. Доступы передаются отдельно через существующие компании/проекты; новых прав, ключей или расходов при упаковке не создано.

## Решения владельца

Согласно сообщениям владельца, поставщик согласился на продажу результата в интерфейсе Affsiwen, без выдачи клиенту аккаунта/ключа поставщика. Пока используются официальные тарифы; будущие объёмные скидки не закладывать в экономику. Подписанный договор/письмо не находится в пакете и независимо не проверялся. Перед коммерческим запуском владелец должен передать документ ответственному лицу закрытым каналом.

Не считать прошлые предложения Yext, mobile DSP или комиссионной модели Apify текущей дорожной картой. Это история поиска. Текущая продуктовая база — брендированный доступ к результатам обработки данных через Bright Data, с чатом Anthropic.
